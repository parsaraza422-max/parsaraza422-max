Reza Plus - Android Kivy starter project

This is a runnable offline prototype with navigation for 6 sections.
AI, online chat, notifications, game downloads and classifieds are DEMO PLACEHOLDERS and need backend services for real functionality.

On a supported Linux Buildozer setup:
  buildozer android debug

On desktop with Kivy installed:
  python main.py

The ZIP contains source code, NOT an installable APK.
